2. Какие данные собирает Приложение

2.1. Данные, которые вы вводите самостоятельно

Приложение работает локально на вашем устройстве. Все данные, которые вы вводите, сохраняются только в памяти вашего телефона и не передаются на серверы разработчика:

  • Профиль: имя, пол, возраст, рост, вес, уровень активности, цель тренировок, опыт, доступное оборудование, ограничения по здоровью.
  • Тренировки: планы, выполненные подходы, веса, повторения, длительность.
  • Питание: приёмы пищи, калории, БЖУ, потребление воды.
  • Замеры тела: вес, обхваты, процент жира.
  • Фотографии прогресса: снимки тела, которые вы делаете сами.
  • Заметки: текстовые примечания к тренировкам и замерам.

2.2. Данные, собираемые автоматически

Приложение использует Firebase Analytics (Google) для сбора анонимной статистики использования:

  • События: запуск приложения, начало и завершение тренировки, открытие Premium-экрана, покупки.
  • Технические данные: тип устройства, версия ОС, версия приложения, язык.
  • Не собираются: ваше имя, контакты, местоположение, содержимое тренировок и фотографий.

Firebase Analytics не передаёт ваши личные данные в FitPlanner и используется только для улучшения продукта.

2.3. Данные, которые Приложение НЕ собирает

Приложение не собирает и не передаёт:

  • Ваши контакты, SMS, историю звонков.
  • Геолокацию.
  • Содержимое ваших фотографий прогресса (они остаются только на устройстве).
  • Пароли, банковские данные (оплата проходит через RuStore Pay).

3. Где хранятся данные

3.1. Локальное хранилище

Все данные профиля, тренировок, питания, замеров и фото хранятся в защищённом хранилище приложения на вашем устройстве (DataStore Preferences и файловая система).

3.2. Резервное копирование

Если на вашем устройстве включено резервное копирование Android (Google Drive), данные Приложения могут попадать в вашу личную резервную копию. Это стандартное поведение Android. Вы можете отключить его в настройках системы.

Приложение не отправляет ваши данные на серверы разработчика.

3.3. Firebase Analytics

Анонимные события Firebase Analytics хранятся на серверах Google в соответствии с политикой конфиденциальности Google .

4. Как используются данные

Ваши данные используются только для:

  • Расчёта персонального плана тренировок.
  • Расчёта нормы калорий и БЖУ.
  • Показа вашего прогресса в графиках и календаре.
  • Отображения напоминаний о весе, воде, еде и абонементе.

Данные не используются для рекламы, не продаются и не передаются третьим лицам.

5. Передача данных третьим лицам

Разработчик не передаёт ваши данные третьим лицам, за исключением:

  • Firebase Analytics — анонимные события использования.
  • RuStore Pay — при совершении покупок (обрабатывает платежи RuStore, разработчик не получает данные вашей карты).
  • По требованию закона — если это предусмотрено законодательством РФ.

6. Разрешения приложения

Приложение запрашивает следующие разрешения:

  • Уведомления (POST_NOTIFICATIONS) — для напоминаний о весе, воде, еде и абонементе.
  • Вибрация (VIBRATE) — для сигнала окончания отдыха между подходами.
  • Камера / галерея — только когда вы добавляете фото прогресса (доступ через системный выбор).

Приложение не запрашивает доступ к геолокации, контактам, микрофону.

7. Ваши права

Вы вправе:

  • Просматривать все свои данные в соответствующих разделах Приложения.
  • Удалить все данные через кнопку «Сбросить всё» в Профиле.
  • Удалить фотографии прогресса в разделе «Замеры тела → Фото».
  • Отключить Firebase Analytics, удалив Приложение.

8. Данные детей

Приложение не предназначено для детей младше 14 лет. Разработчик сознательно не собирает данные детей. Если вам стало известно, что ребёнок использует Приложение — свяжитесь с нами.

9. Изменения в Политике

Разработчик вправе изменять настоящую Политику. Актуальная версия всегда доступна по адресу: [URL политики]. При существенных изменениях Приложение покажет уведомление.
